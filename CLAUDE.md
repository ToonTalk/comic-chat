# Web Comic Chat

Faithful web port of Microsoft Comic Chat (1996). `index.html` is the local
app; `comic-chat-ai.html` + `comic-chat-artpack.json` are the claude.ai
artifact build. Artwork and layout rules come from the MIT-licensed
microsoft/ComicChat repository (artwork (c) 1996-1998 Microsoft, drawn by Jim
Woodring) - keep the copyright notice.

The deployment target for the AI build is a claude.ai artifact. Sandbox
behaviors that shaped this code (downloads, file pickers, dialogs, clipboard,
keyboard, publish size cap):

@claude-artifact-sandbox-notes.md
